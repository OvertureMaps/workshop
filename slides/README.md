# Workshop slides (deprecated)

> **These slides are out of date and are no longer maintained.**

the `*.md` files, using `<<<` / `>>>` separators and `.fragment` markers) that
accompanied an earlier version of the workshop. The **slide mechanism is no
longer being updated**, and the content here may not reflect the current
Overture data, schema, tooling, or methodology.

**The numbered lessons in the repo root (`1-what-is-overture.md` …
`9-transportation-matching.md`) are the maintained source of truth.** Start
there — see the [workshop README](../README.md).

The conceptual material that previously lived only in these slides has been
folded into the lessons:

- the **"data conflation tax"** framing → [Lesson 1](../1-what-is-overture.md)
- the **"GERS is a system" (five components, including the Registry)** framing →
  [Lesson 4](../4-gers.md)

The demo slides (LSIB, MGCP) are covered in more depth by
[Lesson 6](../6-lsib-demo.md), [Lesson 7](../7-buildings-matching.md), and
[Lesson 8](../8-matching-concepts.md).

These files are kept for reference only.
